是否可以进入大量刷题？

满足以下 2 点即可

01

能分题

简单 → 练速度
边界 → 重点内化
难题 → 暂时跳过

边界题：
看答案能懂约 70%，
但自己做容易错。

02

能自己吃透

自己做 → 看标答 → 对比高手路径
→ 模仿 → 关答案重做
→ 独立做对 → 一句话心得

必须：
✓ 关答案能独立做对
✓ 能提炼一句心得

02

大量刷题

先分组，再处理。

分组规则

简单题 → 练速度
边界题 → 重点内化
难题 → 暂时跳过

边界题

看答案能懂约 70%，
但自己独立做容易错。

自己做 → 看标答 → 看懂高手路径
→ 对比自己的路径 → 模仿
→ 关答案重做 → 独立做对
→ 一句话心得

✓ 关答案能独立重做对
✓ 能提炼一句心得

继续讲义迁移

用第一个老师已经学会的思维，
去做其他老师的讲义题。

重点：
做题 → 暴露疑问 → 定点听课 → 补漏洞

不要完整看网课。

只针对疑问点：
拉进度条 / 倍速听

重点放在做题。
