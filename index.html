删除功能指导
  1. 先保存最新的 JSON 完整备份和学习档案，确认文件已下载且可读取。
  2. 手动到 Firebase 清理需要删除的云端学习备份：head、snapshots（包括其 chunks 分片）和 uploads。保留 backup/generation 与 backupCycles 安全元数据，避免破坏旧设备写入保护；不要修改安全规则。
  3. 返回 Pocket，展开下方「重新开始 Firebase 备份」，检查条件并明确确认，以当前本机数据建立新的云端备份起点。

删除云端备份不会清空 Pocket 本机学习数据；重新开始会上传当前本机内容。若要让资料不再出现在新备份中，必须先确认本机也已移除这些资料。

重新开始 Firebase 备份

适用于旧云端备份已手动删除。以当前本机学习数据开始新的云端备份，不恢复旧云端历史，不删除本机数据。

先确认当前项目已部署 Pocket 提供的 protocol 3 Firestore Rules。未部署或不确定时，请先核对并部署现有 firestore.rules，不要放宽规则。执行时会验证旧格式和旧周期写入被拒绝，探测不包含学习数据。请关闭其他 Pocket 标签页。

先检查条件，再明确确认；旧写入保护验证失败时停止。
